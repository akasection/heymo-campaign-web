# Angle Landing Pages

For the sake of the test, all of the landing pages for now are statically hand-crafted instead of dynamically generated.
Eventually this folder will store all building blocks for landing pages, including reusable components, sections and subtemplates.

## quiz.blade.php

This blade is the base part of the quiz. The quiz landing page basically consists of two parts: the preface and the quiz part.
This one shells the quiz. Most of the quiz parts are handled in Vue components.

## unavailable.blade.php

This blade is specially reserved for unavailable landing pages.
